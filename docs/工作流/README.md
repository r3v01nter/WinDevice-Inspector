# 工作流与执行规范

本目录定义 WinDevice-Inspector 的 AI 协作执行流程。所有智能体先阅读根目录 [AI_AGENT_GUIDE.md](../../AI_AGENT_GUIDE.md)，再按本目录规则执行。

## 文件导航
- [工作流总则](工作流总则.md)：角色、权限、状态、任务发布与返修闭环。
- [能力核验清单](能力核验清单.md)：每轮开工前核验模型、仓库、终端、Git 和交付能力。
- [交付中心](../../DELIVERY/README.md)：收件、待审查、审查中、归档和模板入口。

## 当前工作分配
- Gemini 网页端：需求分析、技术方案、任务书和返修任务书。
- Antigravity + Gemini 4 Hydrogen Extra High：独立开发、工作区文件修改、测试和完整交付包制作。
- ChatGPT GPT-6：独立审查、审查记录和约定的归档维护。
- 项目负责人：授权、人工触发审查、最终验收。

若实际工具能力与上述目标不符，执行者必须按能力核验清单记录并停止在需要人工授权的节点，不得假定能力存在。

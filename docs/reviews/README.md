# 独立审查记录

本目录保存 ChatGPT 对交付包、代码、测试证据和文档变更所做的独立审查报告，以及项目负责人提供的本机验证记录。

## 当前审查

- [TASK-0001 阶段 A R1 独立审查报告](TASK-0001_阶段A_R1_独立审查报告.md)：结论为需修订；R1 方案尚未充分覆盖已确认的完整设备诊断产品目标。

## 命名建议

`REV-任务编号-R轮次_审查报告.md`

例如：`REV-TASK-0001-R1_审查报告.md`。

## 规则

- 每轮审查单独成文，不覆盖旧报告。
- 审查报告与 Gemini 原始交付包分开保存；原始包只放在 `DELIVERY/INBOX/待交付/` 或按批次归档。
- 报告必须写明审查基准分支/提交、审查对象、范围、结论、问题清单和未验证事项。
- 代码审查通过不等于本机运行通过；本机验证必须有实际证据。
- 未经项目负责人明确批准，不得把审查通过等同于最终验收。

## 1. 目标与边界

修复 R1 审查报告全部问题，形成安全、可复核的 Windows 一键诊断采集工具。继续采用 BAT + PowerShell，保持只读、本地优先、默认脱敏；不联网、不上传、不自动提权、不修改驱动或系统设置。本任务不替代 WinDevice-Inspector 主应用 TASK-0001，也不授权其阶段 B。

## 2. 必须完成

1. **隐私闭环**：所有 TXT/JSON/CSV/run_log 持久化内容统一脱敏；覆盖当前用户以外的用户目录路径、主机名、IPv4/IPv6、MAC、序列号、PnP 唯一段、SID、邮箱和异常文本。默认分享报告不得泄露工具绝对路径。提供合成样本验证。
2. **PnP 设备分类**：区分当前存在、非当前存在/隐藏、虚拟和未知设备；尽可能采集 Present、HardwareID、CompatibleID、ClassGuid、Service、父设备/位置路径、状态码和驱动信息。Code 45 不得直接判为当前硬件故障。说明覆盖边界和缺口。
3. **状态双轴**：分别表达 CollectionStatus 与 DiagnosticFinding；在模块和关键子项区分成功、部分成功、失败、权限不足、不支持、跳过、未知，以及正常、异常、警告/可疑等诊断结论。读取成功不等于健康正常。
4. **外部命令处理**：逐条检查 powercfg 等命令的退出码、输出和错误；子项失败不得被总模块 NORMAL 掩盖。
5. **稳定输出**：空数据时仍生成固定列头 CSV，或提供准确 manifest 并同步文档；每次运行目录唯一，不得覆盖既有报告；输出失败必须有非零退出码和可诊断日志。
6. **完整性统计**：提供尝试数、成功、部分成功、失败、权限不足、不支持、跳过、未知计数；区分成功查询但空集合与查询失败。
7. **测试证据**：提供可复跑静态检查和合成测试，覆盖隐私、空结果、部分失败、权限不足、Code 45、同秒重复运行和 CSV 空数据。尽可能在 Windows 11 x64 分别测试 PowerShell 7 与 5.1；未执行项如实标 Not run。

## 3. 交付

Gemini 输出一个完整 ZIP，包含 BAT、PowerShell、配置、说明、测试和完成回执，不逐个文件发送。回执列出实际基准 SHA、文件清单、测试命令/结果、未执行项和已知限制，并提供 ZIP SHA-256。

负责人检查 ZIP 后放入本地暂存区；Antigravity 安全检查、解压整理并推送独立分支 `delivery/WDI-DIAG-001-R2`。不得推送 main、强推或合并 PR。负责人明确触发后由 ChatGPT 审查。

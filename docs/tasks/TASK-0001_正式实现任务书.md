## 1. 项目背景

WinDevice Inspector 是面向 Windows 用户的本地优先设备与系统证据采集工具。它收集硬件、设备、驱动、Windows 配置和可靠性证据，保存本地扫描历史，并帮助用户生成可由本人审阅后分享给 AI 的诊断材料。

产品是证据采集与整理工具，不是自动修复工具；不连接 AI 服务自动上传数据，不擅自修改系统。

### 已确认技术基线

- C# / .NET 10 LTS / WPF。
- 首发平台：Windows 11 x64。
- PowerShell 作为受控、只读的独立子进程采集后端。
- 扫描历史保存在当前用户本地应用数据目录。
- 扫描、原始数据导出均由用户主动触发。
- V1 最终目标包含便携版和安装版；完整打包方案不属于本任务范围。

### 不可违反的产品约束

1. 应用启动、显示首页、读取历史记录时不得启动系统采集。
2. 每次采集都必须由用户主动发起，并在采集开始前展示范围、目的、敏感数据类别和权限要求。
3. 用户取消确认时不得创建或启动采集子进程。
4. 采集只读，不自动提权，不安装、更新、禁用或删除驱动，不修复或调优系统。
5. 不进行遥测、自动上传、云同步或自动连接 AI 服务。
6. 不把真实机器扫描数据、个人路径、凭据或令牌提交到仓库。
7. Gemini 不直接提交或推送仓库；项目负责人检查交付后手动放入唯一交付入口。
8. 不得把未执行的 build/test/runtime 检查写成通过。
9. 未经负责人批准，不得改变产品范围、技术栈、公开数据契约或项目依赖边界。

## 4. 已批准技术决策

### C-01｜JSON Schema v1

首个版本必须包含以下顶层字段：

- `schemaVersion`
- `scanId`
- `collectedAtUtc`
- `timeZoneId`（或语义等价且明确记录时区上下文的字段）
- `computerName`（本机原始值；若不可用，按契约表达未知，不得伪造）
- `applicationVersion`
- `collectorVersion`
- `categories`

每个类别至少包含：

- 稳定的 `id` 和显示名称 `name`
- `status`
- `source`
- `collectedAtUtc`
- `durationMs`（可测量时填写；不可测量时按契约明确为空/未知）
- 结构化 `data`
- `warnings`
- 适用时的 `query` 或 `collectionParameters`，记录实际使用的查询窗口和采集参数

实施要求：
- 在代码中提供 Schema v1 的正式 DTO/contract、序列化规则和验证测试。
- 必填、可空、未知值、枚举状态、日期时间格式和兼容策略必须写清楚。
- 查询参数仅记录真实执行的参数；不得把秘密、令牌或任意命令文本写入结果。
- 类别状态至少支持 Success、Partial、Unsupported、Unavailable、PermissionDenied、Failed、Skipped。
- 单类别失败不得丢弃其他类别成功结果。
- 测试夹具必须使用合成数据，不得提交真实机器标识或用户扫描结果。

### C-03｜PowerShell 7 与 Windows PowerShell 5.1 双版本支持

这是负责人已批准的兼容性要求，不是可选建议。

- 优先检测并使用 PowerShell 7（`pwsh.exe`）。
- 同时支持 Windows PowerShell 5.1（`powershell.exe`）。
- 必须提供两个版本的自动化/集成测试证据；未实际测试的版本不得标记为受支持。
- 至少验证：进程启动和版本检测、非交互执行、UTF-8 JSON 输出、CIM/命令可用性、stdout/stderr 分离、退出码、超时、取消、异常退出、无管理员权限时的降级行为。
- 明确记录运行时实际使用的 PowerShell 版本。
- 某版本不可用或某采集项不兼容时，必须显示明确的受限/失败状态；不得静默假装成功。
- 不修改机器级 ExecutionPolicy，不静默提权，不接受拼接的任意命令。
- 使用固定、随应用交付的只读脚本路径和明确参数。

### D-07｜原始 JSON 导出前提示

- 用户点击 Export Raw JSON 后，先显示一次提示，再打开保存对话框。
- 提示说明原始数据可能包含计算机名、设备序列号、MAC/IP、用户名、路径及设备/系统元数据。
- 用户可继续或取消；取消时不得打开保存对话框，也不得写出文件。
- 这是风险提示，不是自动脱敏。原始 JSON 必须保留真实证据，不得擅自改写或静默删除字段。
- 不自动上传、不自动分享。
- 测试继续与取消两条路径；取消不得调用文件写出逻辑。

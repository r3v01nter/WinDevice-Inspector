## 状态口径

- **待规划**：任务范围或前置条件尚未明确。
- **待生产**：任务书已足够明确，可以交给生产方，但尚未开始。
- **待 Gemini 修订**：上一轮审查要求返工，当前任务书已明确下一轮修订要求。
- **生产中**：生产方已开始执行。
- **待交付**：生产方已完成自检并准备提交完整交付包。
- **审查中**：交付已进入唯一入口，正在独立审查。
- **返工中**：存在明确未解决问题，等待修订或任务书尚待发布。
- **待本机验证**：代码审查已通过，但仍需项目负责人在目标 Windows 环境验证。
- **待负责人验收**：所有适用审查与验证门槛已完成，等待项目负责人明确批准。
- **验收通过**：适用的审查与验证门槛均已满足，且项目负责人明确批准。
- **已归档**：原始交付和审查记录已按规则保存；归档本身不自动代表验收通过。
- **已暂停 / 已取消 / 被其他任务替代**：特殊状态，必须保留原因、时间和关联任务。

## 维护约束

1. 不把审计建议、开发路线或 Gemini 自述写成已实施事实。
2. 每个任务必须有稳定编号；返修使用 R1、R2 等轮次，不另造任务编号。
3. 每次交付审查都记录具体文件、审查轮次和结论。
4. 任务编号、任务书标题、当前状态和链接必须与当前任务指针保持一致。

## 状态口径

- **待规划**：需求或前置条件尚未明确。
- **待生产**：任务书完整且前置条件满足。
- **生产中**：执行方已开始工作。
- **待交付**：执行方已完成自检并准备提交。
- **审查中**：交付已进入唯一入口。
- **返工中**：审查发现明确问题，等待修订。
- **待本机验证**：独立审查通过但仍需目标环境验证。
- **待负责人验收**：所有适用技术门槛完成，等待负责人明确批准。
- **验收通过**：适用审查与验证门槛满足且负责人明确批准。
- **已关闭**：任务完成最终验收及收尾。
- **已归档**：原始交付与审查记录已保存；归档不自动代表验收通过。
- **已暂停 / 已取消 / 被替代**：必须记录原因和关联任务。

## 维护约束

1. 不把执行方自述、建议或计划写成已实施事实。
2. 每个任务使用稳定编号；返工使用 R1、R2 等轮次。
3. 每轮审查记录具体文件、结论和证据。
4. 当前任务指针与索引保持一致；并行独立工具不自动替换主线当前任务。
5. 交付上传不代表审查通过、本机验证通过或最终验收。

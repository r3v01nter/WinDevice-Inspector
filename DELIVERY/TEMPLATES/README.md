# 交付中心模板

交付中心统一复用 docs/templates/ 中的维护模板，避免出现两套互相冲突的模板。

- [任务书模板](../../docs/templates/任务书模板.md)
- [完成回执模板](../../docs/templates/完成回执模板.md)
- [审查报告模板](../../docs/templates/审查报告模板.md)
- [缺陷记录模板](../../docs/templates/缺陷记录模板.md)

每轮实施者还应提供：完整 ZIP、文件清单、测试命令与结果、未执行项、已知限制、基线 SHA、分支与提交 SHA（如已推送）、ZIP SHA-256。

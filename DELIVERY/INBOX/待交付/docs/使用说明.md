# Windows 一键诊断信息采集工具 — 使用说明（WDI-DIAG-001）

## 1. 运行前准备

1. **必须先完整解压**：请先将 `WDI-DIAG-001_Win11_Diagnostic_Tool.zip` 解压到本地任意文件夹（支持中文路径，例如桌面 `C:\Users\你的名字\桌面\WDI-DIAG-001\`）。**请勿在压缩包预览窗口中直接双击运行**。
2. **系统要求**：Windows 11（64 位优先），内置 Windows PowerShell 5.1 或已安装 PowerShell 7（`pwsh.exe`）均可直接运行，无需安装额外运行库。
3. **权限建议**：
   - **默认普通权限运行即可**：直接双击 `一键诊断采集.bat`，即可完成绝大多数硬件、设备管理器、驱动、电源、网络与系统日志采集。
   - **可选管理员权限**：若部分受限日志或存储健康指标提示 `ACCESS_DENIED`（权限不足），可右键 `一键诊断采集.bat` 选择“以管理员身份运行”再采集一次。本工具**绝不强制提权**。

## 2. 一键使用步骤

1. 双击文件夹内的 **`一键诊断采集.bat`**。
2. 等待终端自动完成环境检查与 8 大模块只读采集（通常耗时 15–60 秒）。
3. 采集完成后，窗口会显示报告保存目录，例如：
   `output\WDI_Diag_20261127_143015\`
4. 打开该目录，您会看到：
   - **`diagnostic_report.txt`**：综合诊断报告（优先发给 AI 或直接用记事本阅读）。
   - **`diagnostic_data.json`**：完整结构化数据（适合需要深度排查设备树、驱动版本或完整事件明细时交给 AI）。
   - **`csv\` 目录**：适合用 Excel 打开筛选的表格（`devices_pnp.csv`、`drivers.csv`、`system_events.csv`、`disks_and_volumes.csv`、`network_adapters.csv`）。
   - **`run_log.txt`**：本次采集逐项成功/失败与耗时的执行日志。

## 3. 自定义配置与隐私脱敏（`config\config.json`）

打开 `config\config.json` 可按需调整（修改后保存即可生效）：

- `collection.logLookbackDays`：系统日志回溯天数，默认 `7`（允许范围 `1`–`90`）。
- `collection.maxEventsPerCategory`：每类日志最多保留条数，默认 `100`（允许范围 `10`–`500`）。
- `collection.includeCsvReports`：是否同时生成 CSV 表格，默认 `true`。
- `privacy.enabled`：隐私脱敏总开关，默认 `true`。
- `privacy` 子项：可逐项开关 `redactUserName`（用户名）、`redactComputerName`（计算机名）、`redactIpAddress`（IP 地址）、`redactMacAddress`（MAC 地址）、`redactDiskSerial`（磁盘/硬件序列号）、`redactDeviceUniqueId`（设备实例唯一段）、`redactOtherPii`（SID 与邮箱）。

## 4. 安全与隐私声明

- **严格只读**：本工具不修改注册表、不修改系统设置或电源计划、不安装/卸载驱动、不清理日志、不删除用户文件、不做任何自动修复。
- **100% 本地运行**：不联网、不接入遥测、不自动上传或连接任何 AI 服务；是否分享报告完全由您本人决定。

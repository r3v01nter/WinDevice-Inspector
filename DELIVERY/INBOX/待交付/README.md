# 待交付

此目录是仓库内唯一的交付收件入口，路径保持平面：DELIVERY/INBOX/待交付/。

默认流程：Antigravity 中的 Gemini 4 Hydrogen Extra High 按已批准任务书独立开发并生成完整 ZIP；在具备仓库写权限时，Antigravity 将本轮完整交付和清单提交到任务轮次专属分支，并推送到本目录。Gemini 网页端负责任务规划和任务书，不与 Antigravity 并行修改同一工作区。

每次提交必须附带任务编号、轮次、基准 SHA、分支名、commit SHA、文件清单、实际测试结果、未执行项、已知限制和 ZIP SHA-256。若当前 Antigravity 环境不具备 Git 写权限，则不得声称已推送；应将 ZIP 和能力核验结果交给负责人，等待决定。

规则：
- 每个任务/轮次使用独立分支，例如 delivery/WDI-DIAG-001-R2。
- 保留原始文件名及 ZIP 内部必要目录结构，不创建任务专属子目录。
- 不覆盖历史轮次，不提交凭据、个人数据或真实设备扫描数据。
- Antigravity 不推送 main、不强制推送、不合并 PR。
- 推送完成后，项目负责人明确通知 ChatGPT 开始审查；不会自动推进。
- 文件上传不代表审查通过或验收通过。

ChatGPT 的审查结论、归档和后续任务安排，以项目负责人明确触发后的实际检查为准。

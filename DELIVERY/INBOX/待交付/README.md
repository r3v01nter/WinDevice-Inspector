# 待交付

此目录是仓库内唯一的交付收件入口，路径保持平面：`DELIVERY/INBOX/待交付/`。

Gemini 网页端生成完整文件或 ZIP；项目负责人下载后放入本地忽略目录 `DELIVERY/LOCAL_STAGING/待上传/`。Antigravity 按照任务书和 [AI 交付操作手册](../../../docs/AI_交付操作手册.md) 检查、解压、整理，并将本轮交付内容提交到独立分支，再推送到本目录。

规则：
- 每个任务/轮次使用独立分支，例如 `delivery/TASK-0001-R2`。
- 保留文件原名及 ZIP 内部必要目录结构，不创建任务专属子目录。
- 不覆盖历史轮次，不提交凭据、个人数据或真实设备扫描数据。
- Antigravity 不推送 `main`、不强制推送、不合并 PR。
- 推送完成后，项目负责人明确通知 ChatGPT 开始审查；不会自动推进。
- 文件上传不代表审查通过或验收通过。

ChatGPT 的审查结论、归档和后续任务安排，以项目负责人明确触发后的实际检查为准。

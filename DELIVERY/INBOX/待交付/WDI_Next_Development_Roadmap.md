### 第三步：执行下一项软件实现任务 `TASK-0001`（尚未开始实现）

- **目标任务**：`TASK-0001` — First Runnable Vertical Slice（首个可运行垂直切片，当前状态 `待生产`，**尚未启动**）。
- **核心价值**：打通 WPF 无扫描初始界面 → 显式确认门禁 → 受控 PowerShell 只读子进程 → 版本化 JSON 契约 → 本地历史与原始 JSON 导出 → 单元测试全链路。
- **本机实测验收门槛（未经实测不得标为 `验收通过`）**：
  1. 启动应用不触发任何 PowerShell 进程或硬件查询；
  2. 点击 `Start Quick Collection` 展示采集范围与敏感提示，取消绝不启动子进程；
  3. 非管理员权限下确认扫描，产出符合约定 Schema 的本地 JSON 并展示 9 类初始状态（单项失败不影响其他类别，失败不自动重试）；
  4. 取消/超时可安全终止 PowerShell 子进程树，并按约定标准完成 PowerShell 兼容性核验；
  5. 重启后可打开本地历史而不触发新扫描，可显式导出原始 JSON；
  6. `dotnet build` 与 `dotnet test` 在本机 Windows 11 x64 实测通过，交付文件经 `DELIVERY/INBOX/待交付/` 交 ChatGPT 独立审查并获项目负责人批准。

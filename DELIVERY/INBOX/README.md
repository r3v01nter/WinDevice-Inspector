# 交付收件区

## 唯一交付入口

请将 Gemini 返回、并由你本人检查过的完整交付文件放入：

[`DELIVERY/INBOX/待交付/`](待交付/)

不要另建任务专用收件箱，不要恢复旧路径 `DELIVERY/INBOX/TASK-XXXX/`，也不要把同一轮文件拆散到其他目录。

## 标准流程

1. Gemini 按任务书完成工作，将完整文件和真实完成说明交给你。
2. 你先打开或下载文件，检查内容和敏感信息。
3. 你将本轮完整交付文件上传到 `待交付/`。
4. 你通知 ChatGPT，说明任务编号和本轮交付已就绪。
5. ChatGPT 对照任务书、验收标准和项目约束逐份审查。
6. 如需返修，ChatGPT 给出明确问题清单；Gemini 修订后仍使用同一个入口。
7. 本轮审查处理完毕后，ChatGPT 将原始文件和审查记录按任务编号、轮次归档，再清理本目录中的本轮交付文件。

## 重要区分

**已提交 ≠ 审查通过 ≠ 本机验证通过 ≠ 最终验收 ≠ 已归档。**

归档用于保留历史原件，不代表接受其中全部结论。返修版不得覆盖旧轮次原件。

## 清理规则

每轮处理完成后，`待交付/` 应恢复为仅保留 `README.md` 占位说明的状态。不得删除 `INBOX/README.md` 或 `待交付/README.md`。

## 安全要求

禁止上传密码、访问令牌、私钥、浏览器个人数据、真实设备扫描隐私数据或无关个人文件。

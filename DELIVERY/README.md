# Delivery Area

This area is reserved for AI implementation handoffs.

- INBOX/: newly returned task packages waiting for review.
- ARCHIVE/: original packages retained after review when useful.

The project owner places Gemini's complete delivery package in INBOX/TASK-XXXX/. ChatGPT reviews it against the task brief before accepted files are integrated into src/, tests/, and docs/.

Do not put credentials, tokens, real machine scan data, or unrelated personal files here. Keep the README placeholders in both subdirectories.

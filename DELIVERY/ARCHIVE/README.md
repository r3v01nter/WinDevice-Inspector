# Delivery Archive

This directory retains original handoff packages by task or audit identifier, including packages that are pending rework as well as packages that have completed review.

Each archived package must include a README that states its review and acceptance status. **Archiving preserves a record; it does not mean the package was accepted.**

- Pending rework: preserve the original package and record the review findings.
- Accepted: retain the original package when useful for traceability; canonical accepted source and documentation belong in their normal project locations.
- Do not overwrite original submissions with revised versions. Treat each delivery round as a distinct record where needed.

Do not store secrets, credentials, tokens, browser profiles, real private device scan data, or unrelated personal information here.

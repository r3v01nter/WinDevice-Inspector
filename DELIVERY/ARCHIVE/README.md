## Rules

- Pending rework: preserve every original file and matching review report.
- Accepted: retain original delivery for traceability; canonical accepted sources belong in their normal project locations.
- Never overwrite an earlier round with a later round.
- Do not archive secrets, credentials, tokens, browser profiles, real private device scan data, or unrelated personal information.
- Archiving never implies review approval, owner acceptance, or merge to main.

## 2. 总体架构与兼容性设计

- **启动入口层（`一键诊断采集.bat`）**：
  - 采用 **UTF-8 无 BOM + CRLF**，`chcp 65001` 适配中文终端与中文路径；
  - 显式剥离 `%~dp0` 末尾反斜杠，避免传入 PowerShell CLI 时发生 `\"` 引号转义错误；
  - 优先探测 PowerShell 7（`pwsh.exe`），不存在时自动回退 Windows PowerShell 5.1（`%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`）；
  - 使用 `-NoProfile -NonInteractive -ExecutionPolicy Bypass -File` 启动进程级只读子进程，不修改系统或用户级执行策略。
- **采集与脱敏引擎（`scripts\Collect-WinDiagnostics.ps1`）**：
  - 采用 **UTF-8 带 BOM + CRLF**，确保 Windows PowerShell 5.1 与 PowerShell 7 均正确解析全部中文字符；
  - 严格使用 PS 5.1 / 7 双兼容语法（避免 `??`、`?.`、三元运算符与 `-AsArray` 等 7.x 专属语法），使用 `Get-CimInstance` 替代已废弃的 `Get-WmiObject`；
  - 每个大类均由 `Invoke-SafeSection` 包裹独立 `try/catch`，单项失败或权限不足时准确落入 `FAILED` / `ACCESS_DENIED`，绝不中断整体流程，也绝不误判为 `NORMAL`；
  - 对 `Get-PhysicalDisk` 与 `Get-NetAdapter` 提供标准 CIM 回退路径（`Win32_DiskDrive` / `Win32_NetworkAdapterConfiguration`），适配精简版或模块受限环境；
  - 输出编码策略：`diagnostic_data.json` 采用 UTF-8 无 BOM（符合 RFC 8259），`diagnostic_report.txt`、`run_log.txt` 与全部 CSV 文件采用 UTF-8 带 BOM，确保 Windows 记事本与中文 Excel 打开无乱码。
- **配置与隐私层（`config\config.json`）**：
  - 配置缺失或格式损坏时自动回退内置默认安全脱敏配置并记录警告，不崩溃、不降级隐私保护。

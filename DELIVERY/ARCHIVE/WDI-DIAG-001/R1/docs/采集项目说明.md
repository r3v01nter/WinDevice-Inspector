## 2. 七态异常判定规则

本工具严格执行以下 7 态枚举，**严禁将读取失败、权限不足或不可测项判为 `NORMAL`**：

- **`NORMAL`**：读取成功，未发现明显异常（日志查询时间窗内无匹配事件按 0 条计为 `NORMAL`）。
- **`ABNORMAL`**：发现明确异常（例如设备管理器非 0 且非 22 错误码、驱动缺失、磁盘 `Unhealthy` 等）。
- **`SUSPECTED`**：存在可疑线索需进一步确认（例如存在近期 Kernel-Power 41 / WHEA / 蓝屏等历史日志，或存在未签名驱动、未知/已禁用设备、磁盘余量低于 5%）。
- **`UNKNOWN`**：无法通过软件确定状态（例如 PSU 电源硬件质量、无法读取的显存值、枚举返回空集）。
- **`FAILED`**：命令执行报错或数据读取异常。
- **`ACCESS_DENIED`**：因权限不足无法读取（如非管理员访问受限通道），单独标记供用户按需以管理员权限复跑。
- **`NOT_SUPPORTED`**：本机硬件或系统不支持（例如台式机无电池）。

## 3. 证据边界与隐私脱敏规则

1. **区分实时状态与历史事件**：设备管理器与磁盘健康反映当前实时状态；系统日志反映过去 N 天的历史线索，**禁止仅凭单一日志事件断言硬件损坏**。
2. **PSU 硬件不可测声明**：纯软件无法测量电源纹波、负载能力或供电元器件健康度，所有报告均显式标注 `psuHardwareQualityStatus = "UNKNOWN"`。
3. **保留诊断价值的默认脱敏**：
   - 用户名 / `C:\Users\<name>\` → `[USER_REDACTED]`
   - 计算机名 → `[HOST_REDACTED]`
   - IP 地址 → 保留私网段前缀（如 `192.168.x.x`、`10.x.x.x`）或公网首段，隐藏主机位
   - MAC 地址 → 保留前 3 字节 OUI 厂商标识（如 `AA:BB:CC:XX:XX:XX`）
   - 磁盘/主板/内存/BIOS 序列号 → 仅保留末 4 位或完全隐藏（`[SERIAL_REDACTED_xxxx]`）
   - PnP 设备实例 ID → 保留 `PCI\VEN_xxxx&DEV_xxxx` / `USB\VID_xxxx&PID_xxxx` 硬件型号段，仅脱敏末尾唯一实例序列段
   - SID 与邮箱 → `S-1-5-21-[SID_REDACTED]` / `[EMAIL_REDACTED]`

## 3. 建议修正项

### R1-06｜任务书模板的分支字段需避免默认指向 main

**位置：** 现有 `docs/templates/任务书模板.md`。

现有模板有“目标分支：main”，而新速读头又要求任务轮次专属交付分支。建议调整为分别填写：
- 基准分支（通常 main）；
- 基准 commit SHA；
- 本轮交付分支（例如 `delivery/<TASK>-<R#>`）。

不能让执行方把 main 误认为本轮允许写入的目标分支。
